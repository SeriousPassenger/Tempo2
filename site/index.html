Portable profiles

Export the selected profile as JSON and import it on another browser or device. Exported timers are paused at the export time; your live sessions keep running here.

Current profile

Profiles organize data on this browser. They are not password-protected accounts and do not sync automatically.

Keep a backup

Clearing site data, changing browser profiles, or using private browsing can remove local data. Download JSON backups regularly. Your trackers and backups are never uploaded.

How time works

Daily totals reset at your device's local midnight. Timers use saved timestamps and keep counting until paused, even with the page closed. Screen time is recorded manually. Historical entries keep their original local date.

Use Undo to correct an entry. Sessions crossing midnight are undone as a single session. Archive keeps your history.

Moving from the Python version?

The project includes an optional SQLite-to-JSON converter. Its output imports here. The deployed website itself does not use Python or a server database.
